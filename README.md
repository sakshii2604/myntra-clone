🛍️ Myntra Clone

A fully responsive Myntra Clone inspired by Myntra, built to deliver a seamless fashion e-commerce experience. The project replicates core functionalities of an online shopping platform with a modern UI, responsive design, and smooth user experience.

🚀 Features
🛒 Add to Cart functionality
❤️ Wishlist management
🔍 Product Search & Filtering
👤 User Authentication (Login/Signup)
📱 Fully Responsive Design
🧾 Product Details Page
💳 Checkout UI
🎨 Clean and Modern Interface
